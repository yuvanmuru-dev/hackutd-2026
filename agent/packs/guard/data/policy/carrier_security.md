# Carrier account security

## SIM Protection
SIM Protection helps block unauthorized SIM changes. The primary account holder can manage this protection; T-Mobile says only that holder can remove it.
Source: https://www.t-mobile.com/support/plans-features/help-with-t-mobile-account-fraud

## Port Out Protection
Port Out Protection helps block unauthorized transfers of a phone number to another carrier. T-Mobile explains how account holders request a Number Transfer PIN through T-Life or T-Mobile.com.
Source: https://www.t-mobile.com/support/plans-features/help-with-t-mobile-account-fraud

## Titan demo rule
Titan never asks for a PIN, password, one-time code, or transfer PIN, and never sends a link in a text. Its tools only read account state; the brain owns protection changes and customer approvals.
Source: https://github.com/yuvanmuru-dev/hackutd-2026/blob/main/docs/DECISIONS.md

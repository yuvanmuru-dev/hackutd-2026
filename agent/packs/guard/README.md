# Guard data and tools

Run from the repository root:

```bash
PYTHONPATH=agent python3 -m packs.guard.generator
PYTHONPATH=agent python3 -m packs.guard.generator --check
PYTHONPATH=agent python3 -m unittest packs.guard.test_tools packs.guard.test_external -v
```

The generator writes deterministic synthetic account histories and 280 generated
scenarios. Together with the 20 seed scenarios, the dataset has 300 cases. The
read-only `--check` validates the generated bytes and contract shapes. The fixed
90-day baseline window is recorded in `data/personas.json`; histories are sparse
account events, so they contain no daily movement trail. Bill and plan visits
use logins and optional normal portal signals, and care visits use successful
care-channel PIN attempts (D-033).

`DatasetScenario.generator.variant` identifies an attack or normal-behavior
family for ML splits. Keep whole variants out of training for evaluation. Code
relay uses `label: coached` and `variant: code_relay` (D-031). Hard negatives
include travel, normal overnight use, a store upgrade, and a known family call.
Each applicable scenario has one `line.region` snapshot just before its trigger;
normal baseline history contains no line-region snapshots (D-034).

`tools.py` exports the nine `TOOLS` callables and `TOOL_SCHEMAS`. Call a tool as
`TOOLS[name](store, **args)`. Outputs contain `summary`, `result`, and `source`.
Tools read account and protection records; state transitions belong to the brain.
Location comparison returns `match: null` when either signal is unavailable.

`data/synthetic_registry.json` contains every demo scam domain. A listed name
and its subdomains bypass both live providers and carry the exact source
`Synthetic demo registry (simulated RDAP)` (D-038). The T3 age of three days is
simulated data. Other names use registry RDAP discovered through IANA and
URLhaus with `URLHAUS_AUTH_KEY` from the environment. Missing keys and failed
lookups remain unverifiable; absence from URLhaus does not prove a link safe.

Policy lookup uses NVIDIA NeMo Retriever embeddings when `NVIDIA_API_KEY` is
available. Missing credentials or provider failures produce a labeled local
keyword fallback over the same sourced policy passages. Runtime provider
metadata and embeddings are cached in the ignored `agent/cache/` directory.
Secrets and message bodies are not written to that cache.

The offline tests mock HTTP. Live RDAP has been exercised; live authenticated
URLhaus and NVIDIA retrieval still require the brain machine's keys.

# HackUTD 2026

One agent brain (Nemotron) with many doors: web, phone and email. It checks claims against real data,
takes actions and keeps watching. The domain is decided at kickoff.

Start here, in order:
1. docs/GAMEPLAN.md: the bet, the idea bank, the timeline
2. docs/KICKOFF.md: what to do before and right after tracks drop
3. docs/LANES.md: who owns what, plus the prompt to paste into your agent
4. docs/CONTRACTS.md + contracts/: the API everyone builds against
5. AGENTS.md: rules every coding agent follows

Starter quick check (pre-event boilerplate):
`cd agent && python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt && python test_loop_offline.py`
